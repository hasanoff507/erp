## Ilovani qurishdan oldin hal qilinishi shart (blokerlar)

Bular — spec tuzatilgandan keyin ham **hali ochiq** qolgan, loyihaning boshlanishiga yoki markaziy oqimga to'g'ridan-to'g'ri ta'sir qiladigan masalalar:

1. **CRPT Turon (Asl belgisi) integrator API hujjatlari yopiq** (403 xatosi) — markirovkalangan tovar sotuvi (M01/US-M01-03) va offline markirovka siyosati shu integratsiyaga bog'liq. Yechim topilmaguncha markirovka moduli texnik xavf ostida.
2. **my.soliq.uz'dan rasmiy dasturiy (API) o'qish yo'li yo'q** — mahsulotning markaziy qiymat taklifi (BP-08, davlat hisobotini solishtirish) MVP'da qo'lda/yarim-avtomatik boshlanadi. Bu avtomatlashtirish va'dasini kechiktiradi — pilot oldidan aniqlashtirilishi shart.
3. **Tuzatish/e'tiroz yuborish protsedurasi va kanali** (BP-08, 5a-qadam) — 5 kalendar kunlik muddat va huquqiy asos endi aniq, lekin tuzatishni qayerga (alohida ariza? my.soliq.uz shaxsiy kabinetida to'g'ridan-to'g'ri?) va qanday yuborish kerakligi hali noma'lum. Shu protsedura aniqlanmasa, US-M10-02'ning "tuzatish yuborildi" holati amalga oshmaydi.
4. **O'RQ-764 (Kiberxavfsizlik to'g'risidagi qonun) sertifikatlash talabining oddiy xususiy SaaS ERP'ga tegishliligi noaniq** — "ha" bo'lsa, butun MVP jadvaliga katta ta'sir qiladi (ekspertiza/sertifikatlash vaqti va xarajati).
5. **E-IMZO'ning rasmiy dasturchi hujjati yo'q** (faqat jamoatchilik GitHub repo) — e-faktura/e-TTN/hisobot imzolash integratsiyasi (M07, M10, BO-15) kutilganidan ko'proq vaqt olishi mumkin.
6. **Obuna narxi (ARPU) qarori yo'q** — 149k/349k/699k so'm (dastlabki) va 69k–999k (hozirgi, izohsiz) o'rtasida rasmiy tanlov yo'q. Pilot/sotuv boshlanishidan oldin Egasi/mahsulot rahbari tomonidan yakuniy qaror kerak.
7. **Markirovkalangan tovarni offline sotish/qaytarish/ko'chirish siyosati** (ruxsat/taqiq) hal qilinmagan — CRPT Turon API yopiqligi sababli (band 1 bilan bog'liq). MVP standart xatti-harakati ("sotuv rad etiladi") hozircha faqat **taxmin**.
8. **Davlat hisoboti hujjat darajasida (chek/e-faktura) yoki faqat yig'ma summa darajasida kelishi** (BO-10'ning qator-ma-qator farq jadvali) — my.soliq.uz'da rasmiy API yo'qligi sababli tasdiqlanmagan, UI ikkala variantni ham zahira sifatida saqlaydi, lekin bu arxitekturaga ta'sir qiladi.
